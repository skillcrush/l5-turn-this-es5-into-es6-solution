# l5-turn-this-es5-into-es6-solution

A React app created with [Create React App](https://create-react-app.dev/).

## Prerequisites

- [Node.js](https://nodejs.org/) (LTS version recommended)
- npm (comes with Node.js)

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/skillcrush/l5-turn-this-es5-into-es6-solution.git
   cd l5-turn-this-es5-into-es6-solution
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

## Running the app

Start the development server:

```bash
npm start
```

Then open [http://localhost:3000](http://localhost:3000) in your browser. The page reloads automatically when you edit the code.
